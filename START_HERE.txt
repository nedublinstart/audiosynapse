SYNAPSE — самый простой запуск (Windows)

Нужны: Node.js LTS и Python 3 (Add to PATH).
Git НЕ обязателен для запуска.

1) Открой папку проекта в проводнике
2) В адресной строке проводника напиши:  cmd   и нажми Enter
3) В чёрном окне по очереди:

   npm run setup
   npm run dev

Готово. Откроется http://127.0.0.1:3000
API будет на http://127.0.0.1:8787  (не 8000 — на Win11 8000 часто блокируется)

Остановить: Ctrl+C
Или в другом окне cmd:  npm run stop

---
То же самое кнопками:
  SETUP.bat  (один раз)
  START.bat  (каждый раз)
  STOP.bat

---
Если ошибки — открой файл:  FIX_WINDOWS.txt
