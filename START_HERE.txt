SYNAPSE — самый простой запуск (Windows)

Нужны: Node.js LTS и Python 3 (при установке галочка «Add to PATH»).
Git НЕ обязателен.

1) Открой папку проекта в проводнике
2) В адресной строке проводника напиши:  cmd   и нажми Enter
3) В чёрном окне по очереди:

   npm run setup
   npm run dev

Готово — браузер откроется сам.

Порты подбираются автоматически:
  сайт  — 3000 (или 3001/3002, если занят)
  API   — 8787 (не 8000: на Windows 11 он часто заблокирован)

Остановить: Ctrl+C
Или в другом окне cmd:  npm run stop

Если что-то не работает:
   npm run doctor
Эта команда покажет, что именно сломано, и что делать.

---
То же самое кнопками:
  SETUP.bat   (один раз)
  START.bat   (каждый раз)
  DOCTOR.bat  (диагностика)
  STOP.bat
