  SYNAPSE — быстрый запуск на Windows 11
═══════════════════════════════════════════════

Нужно один раз: Python 3.10+ и Node.js 18+
  Python: https://www.python.org/downloads/   (галочка "Add python.exe to PATH")
  Node:   https://nodejs.org/

───────────────────────────────────────────────
  1-й клик:  SETUP.bat     (один раз, 5–15 мин)
  2-й клик:  START.bat     (каждый раз)
───────────────────────────────────────────────

START.bat:
  • поднимет backend :8000 и frontend :3000
  • откроет браузер http://127.0.0.1:3000

STOP.bat — остановить всё.

Если SETUP ругается на npm / сеть:
  • выключи VPN или наоборот включи
  • закрой Cursor/антивирус на минуту
  • запусти SETUP.bat ещё раз

Если Windows блокирует скрипты:
  ПКМ по SETUP.bat → Свойства → Разблокировать
  или в PowerShell:
    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Документация API: http://127.0.0.1:8000/docs
