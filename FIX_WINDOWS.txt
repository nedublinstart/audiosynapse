По твоему логу было ТРИ отдельные проблемы. Разберём каждую.


------------------------------------------------------------------------------
ОШИБКА 1.  git не является внутренней или внешней командой
------------------------------------------------------------------------------
Что это значит:
  Git не установлен (или не в PATH). Для ЗАПУСКА Synapse Git НЕ нужен.

Что делать (если хочешь git pull позже):
  1. Скачай: https://git-scm.com/download/win
  2. Установи с галочкой "Git from the command line and also from 3rd-party software"
  3. ЗАКРОЙ все окна cmd и открой новое
  4. Проверь:  git --version

Пока Git нет — просто работай с уже скачанной папкой.


------------------------------------------------------------------------------
ОШИБКА 2.  SETUP FAILED ... python -c from app.main ... SyntaxError
------------------------------------------------------------------------------
Что это значит:
  Устаревший scripts/setup.js неправильно запускал Python на Windows.
  Сами пакеты УЖЕ установились (pip + npm прошли успешно).
  Это НЕ критично — можно запускать приложение.

Что делать СЕЙЧАС (setup уже почти готов):
  Просто запускай приложение (см. ниже). Повторный setup не обязателен.

Если хочешь перепроверить backend вручную, вставь В ТОЧНОСТИ:

  cd /d D:\Пользователь\Документы\audiosynapse-cursor-synapse-mvp-b6a0\backend
  .venv\Scripts\python.exe -c "from app.main import app; print('OK', app.title)"

Должно напечатать:  OK Synapse API   (или похожее)


------------------------------------------------------------------------------
ОШИБКА 3.  WinError 10013 — доступ к сокету запрещён  ← ГЛАВНАЯ ПРИЧИНА
------------------------------------------------------------------------------
Что это значит:
  Windows НЕ ДАЁТ программе слушать порт 8000.
  Часто так бывает из‑за Hyper-V / WSL / Docker / "excluded port ranges".
  Это НЕ баг Python и НЕ "сломался код" — порт 8000 на твоём ПК зарезервирован.

РЕШЕНИЕ A — самый быстрый (без обновления файлов), ДВА окна cmd
------------------------------------------------------------------------------

ОКНО 1 — API (оставь открытым):

  cd /d D:\Пользователь\Документы\audiosynapse-cursor-synapse-mvp-b6a0\backend
  set PYTHONPATH=.
  .venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8787

Должно появиться что-то вроде:
  Uvicorn running on http://127.0.0.1:8787

ОКНО 2 — сайт (оставь открытым):

  cd /d D:\Пользователь\Документы\audiosynapse-cursor-synapse-mvp-b6a0\frontend
  set API_PROXY_TARGET=http://127.0.0.1:8787
  npm run dev -- --hostname 127.0.0.1 --port 3000

Потом в браузере открой:
  http://127.0.0.1:3000

Проверка API в браузере:
  http://127.0.0.1:8787/api/health
  http://127.0.0.1:8787/docs


РЕШЕНИЕ B — после обновления scripts/dev.js (порт 8787 по умолчанию)
------------------------------------------------------------------------------
Если получил новые файлы (или заменил scripts/dev.js):

  cd /d D:\Пользователь\Документы\audiosynapse-cursor-synapse-mvp-b6a0
  npm run stop
  npm run setup
  npm run dev

Скрипт сам возьмёт порт 8787 (или запасной, если 8787 тоже занят).


------------------------------------------------------------------------------
ДОПОЛНИТЕЛЬНО: проверить, почему 8000 закрыт
------------------------------------------------------------------------------
В cmd:

  netstat -ano | findstr :8000
  netsh interface ipv4 show excludedportrange protocol=tcp

Если 8000 попадает в "excluded port range" — это и есть причина 10013.
Не обязательно чинить 8000: используй 8787.

------------------------------------------------------------------------------
ОШИБКА 4.  Чат ИИ молчит / в логе "Couldn't find ffmpeg" (pydub)
------------------------------------------------------------------------------
Это НЕ причина поломки чата. ffmpeg нужен только для редкой обработки аудио
через pydub; текстовый чат работает без ffmpeg.

Реальная причина: старые провайдеры G4F / модели gpt-4o-mini ломали цепочку.
В новой версии backend сначала дергает Gemini (gemini-3.6-flash).

Что сделать:
  1) Обнови файлы backend (ai.py) и backend\.env
  2) В backend\.env должны быть строки:

G4F_MODEL=gemini-3.6-flash
G4F_FALLBACK_MODELS=gemini-3.5-flash-lite,gemini-3.1-pro
G4F_PROVIDERS=Gemini,AnyProvider,PollinationsAI,DeepSeek,Cerebras,OpenaiChat

  3) Полностью останови API (Ctrl+C) и запусти снова на порту 8787
  4) Напиши в чате: привет

Ожидаемый ответ: короткое приветствие от Synapse Tutor.
ffmpeg для чата ставить НЕ нужно.
