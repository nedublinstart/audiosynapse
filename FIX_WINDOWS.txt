ОШИБКА 1.  git не является внутренней или внешней командой
------------------------------------------------------------------------------
Git не установлен. Для ЗАПУСКА Synapse Git НЕ нужен.

Если хочешь обновлять код через git pull:
  1. https://git-scm.com/download/win
  2. Установить с опцией «Git from the command line»
  3. Закрыть все окна cmd, открыть новое
  4. Проверить:  git --version

Без Git обновляй код скачиванием ZIP с GitHub и распаковкой поверх папки.

------------------------------------------------------------------------------
ОШИБКА 3.  WinError 10013 — доступ к сокету запрещён (порт 8000)
------------------------------------------------------------------------------
Windows не даёт слушать порт 8000 (Hyper-V / WSL / зарезервированные диапазоны).
Исправлено: Synapse больше не использует 8000 по умолчанию, берёт 8787.

Ничего делать не нужно, просто:
  npm run dev

Хочешь убедиться, почему 8000 закрыт:
  netstat -ano | findstr :8000
  netsh interface ipv4 show excludedportrange protocol=tcp


------------------------------------------------------------------------------
ОШИБКА 4.  EADDRINUSE 127.0.0.1:3000 — порт сайта занят
------------------------------------------------------------------------------
Висит старый запуск. Исправлено: лаунчер сам берёт следующий свободный порт.

Если хочешь освободить именно 3000:
  npm run stop

Или вручную:

  taskkill /PID <последнее_число_в_строке> /F


------------------------------------------------------------------------------
ОШИБКА 5.  Чат ИИ не отвечает / в логе "Couldn't find ffmpeg or avconv"
------------------------------------------------------------------------------
Предупреждение про ffmpeg — НЕ причина. Текстовый чат работает без ffmpeg.

Реальная причина была в цепочке провайдеров G4F (модели gpt-4o-mini не
подходят провайдеру Gemini). Исправлено: сначала Gemini + gemini-модели,
таймаут 45 секунд на попытку, затем запасные варианты.

Проверь, что в backend\.env стоят строки:

G4F_MODEL=gemini-3.6-flash
G4F_FALLBACK_MODELS=gemini-3.5-flash-lite,gemini-3.1-pro
G4F_PROVIDERS=Gemini,AnyProvider,PollinationsAI,DeepSeek,Cerebras,OpenaiChat

Затем перезапусти:
  npm run stop
  npm run dev

Напиши в чате «привет» — должен прийти короткий дружелюбный ответ.
Если интернет/провайдер недоступен, чат ответит по тексту конспекта
(локальный режим), но не будет молчать.

ffmpeg для чата ставить НЕ нужно.
