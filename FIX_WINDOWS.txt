САМОЕ ГЛАВНОЕ: две команды диагностики. Они сами скажут, что сломано.

  cd /d D:\Пользователь\Документы\audiosynapse-cursor-synapse-mvp-b6a0
  npm run doctor      — окружение: Python, пакеты, порты, распознавание речи
  npm run ai-check    — какие ИИ-провайдеры отвечают из твоей сети

Обычный правильный порядок:

  npm run setup      (один раз)
  npm run dev        (каждый запуск)


ВАЖНО, ЕСЛИ УЖЕ СТАВИЛ СТАРУЮ ВЕРСИЮ (у тебя это так):
пересоздай окружение — новый список зависимостей вдвое меньше и без pydub,
поэтому предупреждение про ffmpeg исчезнет полностью.

  npm run stop
  rmdir /s /q backend\.venv
  npm run setup
  npm run dev

Установка занимает пару минут (примерно 58 пакетов вместо 140).

Порты подбираются автоматически:
  сайт — 3000, если занят → 3001 / 3002 / 3010 / 4000
  API  — 8787, если занят → 8765 / 8899 / 18080 / 8000

------------------------------------------------------------------------------
ОШИБКА 3.  WinError 10013 — доступ к сокету запрещён (порт 8000)
------------------------------------------------------------------------------
Windows не даёт слушать порт 8000 (Hyper-V / WSL / зарезервированные диапазоны).
Исправлено: Synapse больше не использует 8000 по умолчанию, берёт 8787.

Ничего делать не нужно, просто:
  npm run dev

Хочешь убедиться, почему 8000 закрыт:
  netstat -ano | findstr :8000
  netsh interface ipv4 show excludedportrange protocol=tcp

------------------------------------------------------------------------------
ОШИБКА 5.  «Онлайн-ИИ сейчас недоступен» в чате
------------------------------------------------------------------------------
Значит ни один ИИ-провайдер не ответил из твоей сети (частая ситуация:
часть сервисов блокирует доступ по региону).

ШАГ 1. Посмотри, что доступно именно у тебя:

  npm run ai-check

Команда переберёт провайдеров и покажет [OK] / [FAIL] по каждому.
Synapse теперь пробует ~14 бесплатных провайдеров (Gemini, Cloudflare,
Cohere, HuggingSpace, Yqcloud, OpenCode, KiloCode, Perplexity и др.),
каждого — с его собственной моделью, и запоминает первый рабочий.

ШАГ 2. Если все [FAIL] — подключи свой ключ (это надёжнее всего).
Бесплатный вариант — OpenRouter:

  1. https://openrouter.ai → регистрация → Keys → создать ключ
  2. Открой backend\.env блокнотом и впиши:

AI_BASE_URL=https://openrouter.ai/api/v1
AI_API_KEY=sk-or-твой-ключ
AI_MODEL=deepseek/deepseek-chat-v3.1:free

  3. Проверь:  npm run ai-check
  4. Перезапусти: npm run stop  и  npm run dev

Подойдёт любой OpenAI-совместимый сервис: Groq, DeepSeek, Together,
или локальная модель через Ollama (AI_BASE_URL=http://127.0.0.1:11434/v1).

Предупреждение «Couldn't find ffmpeg or avconv» — НЕ причина.
В новой версии pydub вообще не устанавливается.


------------------------------------------------------------------------------
ОШИБКА 6.  Ошибка при транскрибировании аудио
------------------------------------------------------------------------------
Раньше расшифровка зависела от интернет-провайдера и часто падала.

Теперь распознавание речи работает ЛОКАЛЬНО на твоём компьютере
(faster-whisper) — интернет не нужен, регион не важен.

Проверь, что оно доступно:

  npm run doctor

Ожидаемая строка:
  [OK]   Распознавание речи (локально) — faster-whisper: base

Если строка [WARN] — переустанови зависимости:

  npm run stop
  rmdir /s /q backend\.venv
  npm run setup

Как это работает:
  - при первой расшифровке модель скачается автоматически (~150 МБ)
  - лекция на 1 час обрабатывается несколько минут (зависит от процессора)
  - таймкоды [MM:SS] проставляются автоматически

Хочешь точнее (но медленнее) — в backend\.env поменяй:

WHISPER_MODEL=small      (варианты: tiny, base, small, medium)

Поддерживаемые форматы аудио:
  mp3, wav, m4a, ogg, opus, aac, flac, wma, amr, mp4, webm, 3gp, mkv

Если расшифровка не удалась, лекция получает статус «Уточнение» и понятную
подсказку, а конспект всё равно можно собрать из PDF/DOCX-материалов.
Кнопка «Обработать снова» на странице лекции перезапускает обработку.
